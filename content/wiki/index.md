## What is this?

Enchanted Wiki is a documentation site. Every page is a plain `.md` file in `content/wiki`. Folders become sidebar sections and the file name becomes the URL.

| File | URL |
| --- | --- |
| `content/wiki/index.md` | `/` |
| `content/wiki/getting-started/installation.md` | `/getting-started/installation` |
| `content/wiki/guides/admin-panel.md` | `/guides/admin-panel` |

## Where to start

- [Installation](/getting-started/installation): set up the project and your admin login.
- [Writing pages](/getting-started/writing-pages): frontmatter and page structure.
- [Markdown guide](/getting-started/markdown): everything the renderer supports.
- [Images](/getting-started/images): add screenshots and arrange them with drag and drop.
- [Admin panel](/guides/admin-panel): create and edit pages in the browser.

Press **Ctrl K** (or **⌘K** on a Mac) to search pages from anywhere.
