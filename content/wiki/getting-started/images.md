## Adding an image

Open a page in the admin panel. The **Media** panel on the right lists every uploaded image. You can:

1. **Upload** a new file with the Upload button (PNG, JPG, GIF or WebP, up to 10 MB).
2. **Click** an image to add it at the end of the page.
3. **Drag** an image into the layout, dropping it into any gap between blocks.

## Arranging blocks

The **Layout** tab shows each block of the page as a card:

- Drag a card by its grip handle to move it.
- Use the pencil icon to edit a block's markdown.
- Use the trash icon to remove a block.

Images are blocks too, so you can place them between paragraphs exactly where you want them.

## Markdown syntax

```md
![Dashboard screenshot](/uploads/dashboard.png)
```

Write a short description in the brackets. It is used as alt text for screen readers.
